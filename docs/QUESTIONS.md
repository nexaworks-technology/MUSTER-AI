# QUESTIONS

Open questions for the founder. Each one has a **conservative default that does not block M1**. The build proceeds on the
default until answered. An answer that differs is recorded here and in `DECISIONS.md`, and becomes a change in the named milestone.

Status legend: **OPEN** (default in use) · **ANSWERED** (see section C; the row in A/B is kept for history).
