## 1. Goal
Prove value in money. Build the "Did It Work?" Outcome Ledger, the AI accuracy view, pre-made leader reports with a weekly Leader Reporter digest, and Ask AI. Ask AI answers only from cited, scoped data, and every change it proposes needs a confirmation.

## 2. In scope
- **Models** ([W]): `ReportSnapshot`, `AskThread`, `AskMessage`. Complete `OutcomeRecord` fields and checkpoints.
- **Outcome Ledger** (`src/modules/outcomes/`, route `/reports/outcomes`):
  - Complete the 30/90-day checkpoints for all outcome statuses (REPLIED, MEETING_HELD, RECOVERED, RENEWED, EXPANDED, CONTRACTED, CHURNED, NO_CHANGE). Each status stores evidence sources.
  - Views per account, play, agent and signal.
  - The headline sentence is computed deterministically: "In 90 days it flagged N risks, the team acted on A, R recovered or renewed — worth $X". $X is shown only with `canViewRevenue`.
  - Attribution is labelled per Q-15 ("attributed, not proven causal").
  - **Save record (§6H6):** each save or expansion win links to its originating signal and action(s) (approval/task/outbound/playRun ids).
- **AI accuracy view** (`/reports/ai-accuracy`):
  - Per agent and per signal rule: true alarms vs false alarms per Q-16, and CSM acceptance rate (approved / (approved + rejected)).
  - A "cries wolf" list (false-alarm rate above the config threshold) with **Tune** (edit SignalRule params → new value audited) and **Kill** (disable rule, audited) actions.
- **Pre-made reports** (`src/modules/reports/`, route `/reports`):
  - Reports: portfolio health trend, adoption, onboarding time-to-value, renewal outcomes, expansion found, support risk, team activity vs outcomes.
  - Filters: period, owner, tier and segment. No builder.
  - Each report is computed deterministically into `ReportSnapshot` and respects `canViewRevenue` via `redactFinancials`.
  - Every figure opens into its records (Rule 1).
- **Leader Reporter** (`leader-reporter`, `prompts/leader-reporter.md`, tier `standard`):
  - A weekly job `reports.weeklyDigest` per workspace (Monday 07:00 workspace tz).
  - The narrative is written only from the computed ReportSnapshot, citing its fields.
  - Delivered in-app, by email to internal users (not customers, via `src/lib/email` internal transport) and to Slack (M5 adapter).
- **Ask AI** (`src/modules/ask-ai/`, route `/ask`, agent `ask-ai`, `prompts/ask-ai.md`, tier `deep`):
  - **Tools:** scoped read functions only, built on module `service.ts` exports with `scopedDb(ctx)` and the user's permissions/book scope:
    `searchAccounts`, `getAccount360Summary`, `listSignals`, `searchConversations` (returns Extractions + quotes), `listTickets`, `getContract` (respects canViewRevenue), `getHealthWithReasons`, `listPromises`, `listRenewals`, `readDocument`, `readUploadedFile`.
    There is no raw SQL tool and no cross-workspace tool.
  - **Answer schema:** `{ answer, citations[min 1] → tool result record ids, figures[{ value, toolCallId, path }] }`.
  - **Number validator:** every numeric token in `answer` (excluding dates) must appear in a cited tool output, otherwise the answer is rejected and not rendered. An answer with no citation is not rendered (Rule 4).
  - **Missing data:** "I cannot see a contract for this account" — tools return explicit `notFound`, and the prompt requires saying so.
  - **File upload:** a contract or transcript goes through `src/lib/storage`. It is processed only after `scanStatus = CLEAN` (Q-18), the text is extracted, and Q&A cites file offsets.
  - **Voice (Q-11 default):** off by default. When an Admin enables the workspace setting, browser-native dictation fills the text box, with a notice that audio is handled by the user's browser vendor. No server-side audio processing.
  - **Confirmed actions:**
    - Write intents (e.g. "Move these 40 accounts to the Renewal Risk play") produce an `Approval` of kind BULK_ACTION / ENROLL_PLAY / UPDATE_FIELD with the exact change list.
    - Nothing executes until the user clicks **Yes**. Execution goes through the same module services (permission checks per item) and is audited.
    - Partial permission produces a list of skipped items with reasons.

  - RECOVERED needs an improved band that holds for 14 days;
  - RENEWED/CHURNED come from RevenueEvent/Renewal;
  - with no data, NO_CHANGE is stored with evidence `[]`. It is not a failure.

  - IGNORED records never count as saved;

- `src/modules/outcomes/__tests__/accuracy.test.ts`:
  - true/false alarm classification per Q-16;

  - the cries-wolf threshold edge.
- `src/modules/reports/__tests__/<reportKey>.test.ts`: one per pre-made report on fixture data.
- `src/modules/ask-ai/__tests__/tools-scope.test.ts`:
  - a CSM with bookScope OWN cannot see another CSM's account through any tool;
  - workspace B ids return notFound;
  - getContract without canViewRevenue omits values.
- `src/modules/ask-ai/__tests__/answer-validate.test.ts`:
  - no citations → not rendered;
  - a number absent from tool output → rejected;
  - a number present in a cited tool output → accepted;
  - dates are not treated as figures;
  - a citation id not in the tool results → rejected.
- `src/modules/ask-ai/__tests__/confirmed-actions.test.ts`:
  - no confirmation → zero changes;
  - after confirmation, every item is executed via the service with permission checks;
  - partial permission → skipped list;
  - an audit row per item.
- **Tenant isolation:** add ReportSnapshot, AskThread and AskMessage to the tenant suite. Ask AI must not read another workspace through any tool (enumeration over the tool registry).

## 7. Demo script (Larkspur Analytics, SEED_TODAY 2026-11-02)
1. Sign in as **Dana Whitfield** (CS Leader, finance permission). Open **Ask AI**.
2. Ask: "Which accounts mentioned a competitor this month, and what did they say?"
3. The answer lists **Brightwell Logistics** ("Tallyfield") and any other seeded mentions, with verbatim quotes. Each links to the call or email it came from.
4. Ask: "What is Northgate Freight's contract value?" The answer cites the contract. Then ask about an account seeded with no contract: "I cannot see a contract for this account."
5. Ask: "Move these accounts to the Renewal Risk play." A confirmation lists each account and the exact change, with any skipped items explained. Click **Yes**; the PlayRuns start and audit rows exist.
6. Upload the seed contract PDF and ask "What is the notice period?". The answer cites the file passage.
7. Open **Reports → Outcome Ledger**. The 90-day sentence shows flagged / acted / recovered-or-renewed / worth $X, labelled "attributed".
8. Click one saved account to see its save record: signal → approval → sent email → renewed.
9. Open **Reports → AI accuracy**. A noisy signal rule is in "cries wolf". Click **Kill**; the rule is disabled and audited.
10. Open **Reports → Portfolio health trend**, filter by tier Mid-touch, and click a figure to see its records.
11. Sign in as **Leo Marsh** (no finance permission). The ledger shows counts, but money is marked "Restricted".
12. Show the weekly Leader Reporter digest in-app (trigger the job manually in dev) with citations to report fields.
